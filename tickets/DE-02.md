# DE-02 — Robust date parsing

GOAL: `parseDate` in `src/utils/dates.js` handles all date formats present in
`data/team_metrics.csv`.

CONTEXT: Formats in the wild: `YYYY-MM-DD`, `DD/MM/YYYY`, `DD.MM.YYYY`,
`Month D YYYY` (e.g. "June 30 2026"). Ambiguity rule: slash and dot formats
are day-first (European).

CONSTRAINTS:
- Pure function, no date libraries.
- Unparseable input returns an invalid Date (current behavior preserved).

ACCEPTANCE CRITERIA:
- [ ] Unit tests for every format above plus at least two invalid inputs.
- [ ] `formatDate` output remains ISO (YYYY-MM-DD) for all parseable inputs.
- [ ] Existing tests still pass.

VERIFY WITH: `npm test`
