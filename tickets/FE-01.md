# FE-01 — Status badge component

GOAL: Statuses in the dashboard table render as colored badges instead of plain text.

CONTEXT: `src/components/TeamTable.jsx` renders `item.status` as raw text.
Statuses: on-track, at-risk, blocked, done.

CONSTRAINTS:
- New component `src/components/StatusBadge.jsx`; TeamTable uses it.
- Colors via CSS classes in `src/styles.css` (green / amber / red / gray). No inline styles.
- Do not change filtering logic or the API.

ACCEPTANCE CRITERIA:
- [ ] Each of the 4 statuses renders a visually distinct badge.
- [ ] Unknown status values fall back to a neutral badge without crashing.
- [ ] A component test covers all 4 statuses plus the unknown-status fallback.

VERIFY WITH: `npm test`
