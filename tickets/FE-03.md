# FE-03 — Sort table by last-updated date

GOAL: Users can toggle sorting of the table by the "Last updated" column
(newest-first / oldest-first).

CONTEXT: `src/components/TeamTable.jsx`; dates formatted by `src/utils/dates.js`.

CONSTRAINTS:
- Sorting is a pure function in `src/utils/filters.js` (`sortByUpdatedAt(items, direction)`).
- Clicking the "Last updated" header toggles direction; indicate direction visually.
- Do not sort in the component body — use the utility.

ACCEPTANCE CRITERIA:
- [ ] Unit tests for the sort utility (both directions, stable for equal dates).
- [ ] Header click toggles order in the UI; a component test verifies row order changes.

VERIFY WITH: `npm test`
