# QA-01 — Integration tests for /api/metrics

GOAL: The `/api/metrics` endpoint has integration tests covering normal use,
filtering, and misuse.

CONTEXT: `api/app.js`; existing example in `tests/api.test.js` (supertest is installed).

CONSTRAINTS:
- Tests only; do not change endpoint behavior in this ticket. If you find
  questionable behavior, document it in the test file as comments.

ACCEPTANCE CRITERIA:
- [ ] Test: no query returns all items with correct `count`.
- [ ] Test: `?status=blocked` returns only blocked items.
- [ ] Test: `?status=all` behaves like no filter.
- [ ] Test: unknown status value — document the current (silent empty) behavior.
- [ ] Test: unknown route returns 404.

VERIFY WITH: `npm test`
