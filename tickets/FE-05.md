# FE-05 — Accessible chart alternative

GOAL: The story-points chart data is available to screen readers as a visually
hidden data table.

CONTEXT: `src/components/MetricsChart.jsx` renders SVG only; `aria-label` exists
but the per-team values are not exposed as text.

CONSTRAINTS:
- Add a visually-hidden (`.sr-only` class) table with team / points rows inside the chart component.
- Do not alter the visual rendering of the SVG.

ACCEPTANCE CRITERIA:
- [ ] `.sr-only` utility class added to `src/styles.css`.
- [ ] Hidden table rows match the chart data 1:1.
- [ ] Component test asserts the table content for a sample dataset.

VERIFY WITH: `npm test`
