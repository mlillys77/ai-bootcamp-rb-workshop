# DE-01 — Data validation script for team_metrics.csv

GOAL: `npm run validate` fails (non-zero exit) when `data/team_metrics.csv`
contains data-quality problems, and prints a readable report.

CONTEXT: `data/team_metrics.csv` is known to be messy: duplicate rows, null/empty
values, inconsistent status casing, mixed date formats.

CONSTRAINTS:
- Script at `scripts/validate-data.js` (Node, no new dependencies).
- NEVER modify the CSV. Read-only.
- Add `"validate": "node scripts/validate-data.js"` to package.json scripts.

ACCEPTANCE CRITERIA:
- [ ] Detects and reports: exact duplicate rows, empty required fields
      (member, story_points, updated_at), non-canonical status values,
      dates not in YYYY-MM-DD format.
- [ ] Exit code 1 when any problem found, 0 on a clean file.
- [ ] Unit tests for the check functions using inline sample rows.

VERIFY WITH: `npm test && npm run validate` (validate is EXPECTED to fail on current data)
