# FE-02 — Empty state for filtered table

GOAL: When the active filter returns no rows, the table area shows a friendly
empty-state message instead of an empty table body.

CONTEXT: `src/App.jsx` + `src/components/TeamTable.jsx`. Selecting a status with
no matches currently renders headers over nothing.

CONSTRAINTS:
- Message text: "No items match this filter." with a hint to reset to "all".
- Keep the table headers hidden when empty; do not remove the chart.

ACCEPTANCE CRITERIA:
- [ ] Empty result set shows the message; non-empty shows the table as before.
- [ ] A component test covers both states.

VERIFY WITH: `npm test`
